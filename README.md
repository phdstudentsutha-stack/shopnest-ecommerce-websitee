# ShopNest - Static E-Commerce Website

A beginner-friendly static e-commerce landing page built with HTML5, CSS3, Bootstrap 5, Flexbox, responsive media queries and a small JavaScript file.

## Project files
- `index.html` - page structure and content
- `style.css` - styling and responsive layout
- `script.js` - demo search, cart counter and newsletter interaction

## How to run
1. Download and unzip the project.
2. Open the `ShopNest` folder.
3. Open `index.html` in a browser (or use Live Server in VS Code).
4. Internet access is needed for Bootstrap CDN and remote images.

## GitHub submission
Create a repository named `shopnest-ecommerce-website`, upload all three files and this README, then copy the repository URL into your Google Doc.

This is a demo site: the cart and newsletter are front-end interactions only, not connected to a backend.
